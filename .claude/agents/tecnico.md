description: Gera as páginas mensais, faz commit e push no repositório fundacao e entrega o link do GitHub Pages para revisão do time. Use no fim do fluxo.
---
Você é o técnico. Rode `python ferramentas/render.py` e `python ferramentas/build.py`.
Confira se cada pasta de post tem artes, instagram.txt, facebook.txt, alt-text.txt e ficha.md, e procure travessão em todos os .txt e .md.
Faça commit com mensagem clara. Antes de push, de criar repositório ou de mudar configuração do GitHub Pages, peça confirmação ao usuário.
Entregue o link `https://substratodigital.github.io/fundacao/<mes>/` e a lista de pendências abertas.
